# 集成常见问题

## Zendesk

- **支持**：Pro 与 Starter 支持 Zendesk 集成；Free **不支持**
- **开启方式**：登录后进入 **设置 → 集成 → 连接 Zendesk**，按提示授权
- **能力**：可将云席回答中的引用链接附到 Zendesk 工单备注（单向辅助）

## Slack

- 支持将「需要人工跟进」的会话**通知**到指定 Slack 频道
- **不支持** Slack 内完整双向同步工单状态（当前版本）

## API

- Pro 套餐提供只读用量查询 API（密钥在设置中创建）
- 写入类公开 API 不在当前文档范围
